# CanvasX — Academic & Professor Website Builder

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.8-blue.svg)](https://www.typescriptlang.org/)
[![React](https://img.shields.io/badge/React-18.3-61dafb.svg)](https://reactjs.org/)

A dedicated website builder tailored for professors, principal investigators, and academic researchers. Design, customize, and export clean standalone HTML/CSS academic portfolio sites.

</div>

---

## Key Features

- **Academic Profile & Hero**: Faculty title, office location, contact information, research affiliations, and bio tags.
- **Modern Publications List**: Focused purely on title, journal/venue, authors, publication year, and direct links (PDF, publisher site, code, data). Zero wasted margin space and no clutter.
- **Students & Advising Tabs**: Dedicated sections and interactive tabs for PhD Alumni, Current PhD Students, Postdoctoral Scholars, and Masters advisees, displaying dissertation topics, current academic placements, and graduation years.
- **Sidebar Supervision Metrics**: At-a-glance counters for doctoral graduates, active candidates, and postdocs.
- **Inline Rich-Text Editing**: Click any text directly on the canvas to format (Bold, Italic, Underline, Links) and customize.
- **Live HTML/CSS Export**: Export fully self-contained HTML and CSS files ready for GitHub Pages, university web servers, or personal hosting with zero external runtime dependencies.
- **Modular Section Controls**: Toggle profile sections (Hero, Biography, Honors, Publications, Students, Footer) on or off with a single click.

## Tech Stack

- React 18 + TypeScript
- Vite
- Vanilla CSS + Modern Design Tokens
- Google Fonts (Newsreader + Plus Jakarta Sans)

## Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/canvasx.git
cd canvasx

# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit `http://localhost:5173` to start creating your academic portfolio.

---

## Available Scripts

- `npm run dev`: Launch local Vite dev server
- `npm run build`: Production bundle and type check
- `npm run preview`: Preview production build
- `npm test`: Run test suite
