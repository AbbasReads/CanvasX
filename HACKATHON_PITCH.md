## [1:45-2:15] THE TECH (30 seconds)

"Under the hood, we're using:

- **React 18 + TypeScript** for type-safe components
- **Tambo AI** for natural language design commands  
- **shadcn/ui** for beautiful, accessible components
- **Framer Motion** for smooth animations
- **Real-time rendering** - what you see is what you export

Everything runs in the browser. No backend. No vendor lock-in. Export your code and own it forever."
